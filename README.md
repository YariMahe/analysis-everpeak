# analysis-mobility
Este repositorio contiene el análisis realizado a través de datos proporciandos por TomTom Traffic Index y OECD Cities relacionados con la movilidad urbana y la productividad económica en las principales ciudades latinoamericanas.

**Contenido del repositorio**
ladb_mobility_economy.ipynb: Notebook principal con limpieza, outliers e insights.

**Como abrir el Notebook en Google Colab**
1. Clic en el botón "Open in Colab"
*ó*
1. Abre el archivo .ipynb en GibHup
2. Haz clic en Open in Colab

**Cómo reproducir el análisis**
1. Abre notebooks/ladb_mobility_economy.ipynb
2. Ejecuta las celdas en orden
3. El notebook carga automáticamente el dataset desde /data/ o desde un enlace público

**Objetivo del análisis**
1. Identificar problemas de calidad de datos
2. Construir gráficos para concer mejor la distribución de datos en diferentes ciudades
3. Analizar comportamientos, distribuciones y outliers
4. Generar insights para saber en qué ciudades invertir en infraestructura
